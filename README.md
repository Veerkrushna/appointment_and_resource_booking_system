# Appointment & Resource Booking System

A full-stack appointment and resource booking system built with FastAPI and Next.js.

## Tech Stack

### Backend

* FastAPI
* PostgreSQL
* SQLAlchemy
* Alembic
* Redis
* Celery
* Pytest

### Frontend

* Next.js
* TypeScript

## Project Structure

```text
appointment-booking-system/
├── backend/       # FastAPI backend
├── frontend/      # Next.js frontend
└── README.md
```

## Features

* Service management
* Provider/resource management
* Availability calculation
* Appointment booking
* Double-booking prevention
* Cancellation and rescheduling
* Notifications and reminders
* Timezone support
